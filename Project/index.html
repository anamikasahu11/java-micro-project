Scheduling concepts

Useful formulas for your practical.

Turnaround time (TAT) = Completion time - Arrival time

Waiting time (WT) = Turnaround time - Burst time

Response time (RT) = First CPU start - Arrival time

FCFS, SJF, and Priority are non-preemptive. Round Robin is preemptive and shares CPU time using a quantum.

Algorithm guide

Definitions, trade-offs, and common use cases.

FCFS — First Come, First Served

Runs ready processes in arrival order without preemption. It is simple and fair by arrival order, but a long job can make shorter jobs wait (the convoy effect). It is useful for simple batch queues.

SJF — Shortest Job First

Selects the shortest burst among arrived processes and runs it to completion. It often minimizes average waiting time when burst lengths are known, but long jobs may wait and burst estimates are not always available.

Priority Scheduling

Selects the highest-priority ready process; this simulator uses the smaller numerical value as higher priority. It supports differentiated importance, but low-priority processes can starve without aging.

Round Robin

Gives each ready process a time quantum, then re-enqueues unfinished work. It improves fairness and response time for interactive workloads, but small quanta increase context-switch overhead while large quanta approach FCFS.
